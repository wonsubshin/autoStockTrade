2단계: 데이터베이스(DB) 구성 선택

거래 데이터, 10대 퀀트 봇 성과, AI 시황 분석 기록을 저장할 데이터베이스 방식을 선택하세요.

🟢 추천 · 초간편

내장 SQLite (단독 사용)

별도의 DB 서버를 설치할 필요 없이 PC 내부 파일(auto_stock_trade.db, WAL 모드)로 안전하게 거래 및 봇 데이터를 고속 저장합니다.

🔵 고급 · 엔터프라이즈

외부 / 로컬 PostgreSQL 16

보유 중인 PostgreSQL 서버에 연결하여 대용량 실시간 거래 기록 및 이중 백업 스키마를 구성합니다.
