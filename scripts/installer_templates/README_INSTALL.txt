================================================================================
  AutoStockTrader (키움증권 시세 ⨉ 토스증권 매매 AI 퀀트 시스템) 배포 패키지
================================================================================

본 /install 폴더는 개발자가 아닌 일반 사용자도 추가 설정 없이 즉시
주식 자동매매 및 11대 퀀트 봇 가상 아레나 시스템을 실행할 수 있도록
모든 프로그램(백엔드, 프론트엔드, 파이썬 브릿지, 초기 설정 마법사)이
완벽하게 자급자족(Self-Contained) 형태로 패키징된 독립 배포판입니다.

--------------------------------------------------------------------------------
📌 [1] 사전 준비 사항 (무엇이 필요한가요?)
--------------------------------------------------------------------------------
1. Node.js (v20 이상 설치 권장, v22 LTS 추천)
   - 다운로드: https://nodejs.org/ (LTS 버전 다운로드 및 설치)
2. Python 3.12 (또는 Python 3.10 이상)
   - 다운로드: https://www.python.org/downloads/
   - ※ Windows 사용자 주의: 설치 화면 하단의 'Add python.exe to PATH' 반드시 체크!
3. 증권사 및 AI API 키 (설치 마법사 또는 나중에 대시보드에서 등록 가능):
   - 키움증권 Open API (국내 실시간 시세용 - 미보유 시 시뮬레이션 모드로 즉시 체험 가능)
   - 토스증권 Open API (실전 매매 및 잔고 조회용)
   - Google Gemini API Key (무료 발급: https://aistudio.google.com)

--------------------------------------------------------------------------------
🚀 [2] 운영체제별 원클릭 실행 방법
--------------------------------------------------------------------------------
▶ Windows 사용자:
   1. `AutoStockTrader_Windows_Run.bat` 파일을 더블클릭합니다.
   2. 최초 실행 시 웹 브라우저에 [Step-by-Step 설정 마법사] 창이 자동으로 뜹니다.
   3. 마법사 5단계를 거쳐 정보를 입력하고 [시스템 시작]을 누르면 즉시 가동됩니다!
   4. 이후 재실행 시에는 마법사를 건너뛰고 메인 대시보드로 바로 연결됩니다.

▶ Linux 사용자:
   1. 터미널에서 다음 명령을 실행하거나 바탕화면 바로가기 아이콘을 클릭합니다:
      ./AutoStockTrader_Linux_Run.sh
   2. 마법사 브라우저(http://127.0.0.1:9901)가 자동으로 뜹니다.
   3. 설정 완료 후 http://127.0.0.1:9900 대시보드가 자동으로 열립니다.

--------------------------------------------------------------------------------
🗄️ [3] 데이터베이스(DB) 선택 가이드 (마법사 2단계)
--------------------------------------------------------------------------------
• 🟢 [추천] 내장 SQLite 사용 (DB 서버 없음):
  - 별도 DB 서버 설치나 복잡한 비밀번호 설정 없이 PC 내 파일(auto_stock_trade.db)로
    모든 거래 내역과 봇 데이터를 고속(WAL 모드)으로 안전하게 저장합니다.
  - 대부분의 일반 개인 투자자에게 강력 추천합니다.

• 🔵 [고급] PostgreSQL 16 서버 연동 (DB 서버 있음):
  - 이미 PostgreSQL 데이터베이스를 보유하고 계신 경우 호스트, 포트, 계정을
    입력하면 8개 핵심 테이블을 자동으로 생성하고 실시간 이중 백업을 수행합니다.

--------------------------------------------------------------------------------
🛑 [4] 서비스 안전 종료 방법
--------------------------------------------------------------------------------
▶ Windows: `AutoStockTrader_Windows_Stop.bat` 더블클릭
▶ Linux: `./AutoStockTrader_Linux_Stop.sh` 실행

--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
